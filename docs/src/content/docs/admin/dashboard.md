Het **Admin Dashboard** geeft de beheerder een overzicht van de belangrijkste gegevens binnen SuriHealth.

Op het dashboard worden verschillende statistieken en grafieken weergegeven.

![Admin Dashboard](../../../assets/images/admin-dashboard.jpeg)
*Figuur 14. Het Admin Dashboard van SuriHealth.*

## Statistieken

Bovenaan het dashboard worden de belangrijkste aantallen weergegeven:

- **Gebruikers:** het aantal geregistreerde gebruikers.
- **Contact berichten:** het aantal binnengekomen contactberichten.
- **Database recepten:** het aantal beschikbare recepten in de database.

## Registraties

De grafiek **Registraties** toont het aantal gebruikersregistraties gedurende de maand.

De beheerder kan hierbij de registraties van de huidige maand vergelijken met die van de vorige maand.

## Top Triggers

De sectie **Top Triggers** geeft een overzicht van de gezondheidsgerelateerde triggers die het meest voorkomen bij gebruikers.

Hier worden onder andere triggers weergegeven zoals:

- Diabetes
- Cholesterol
- Hoge bloeddruk
- Hart- en vaatziekten

## Jaaroverzicht

Onderaan het dashboard staat een **jaaroverzicht** waarin de registraties gedurende het jaar worden weergegeven.

## Gegevens vernieuwen

Met de knop **Gegevens Vernieuwen** kan de beheerder de weergegeven gegevens opnieuw laden.
