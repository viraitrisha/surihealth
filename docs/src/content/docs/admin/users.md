Via **Users** kan de beheerder de gebruikersaccounts binnen het SuriHealth-platform beheren.

![Admin Users](../../../assets/images/admin-users.jpeg)
*Figuur 17. Het gebruikersbeheer van SuriHealth.*

## Overzicht

Bovenaan de pagina worden verschillende statistieken weergegeven:

- **Gebruikers:** het totale aantal gebruikers.
- **Beheerders:** het aantal gebruikers met een adminrol.
- **Geblokkeerd:** het aantal geblokkeerde gebruikers.

## Gebruikers zoeken

Met het zoekveld kan de beheerder zoeken naar een gebruiker op basis van:

- Naam
- E-mailadres
- Rol

## Gebruikersinformatie

De gebruikers worden weergegeven in een tabel met onder andere:

- Gebruikersnaam
- E-mailadres
- Status
- Rol
- Registratiedatum

De status van een gebruiker wordt weergegeven als bijvoorbeeld **Actief**.

## Gebruikers beheren

Aan de rechterkant van een gebruikersaccount staan de beschikbare beheeracties.

Een beheerder kan bij een normale gebruiker onder andere:

- **Blokkeren**
- **Admin maken**
- **Verwijderen**

gebruiken.

## Beheerdersaccount

Accounts met de rol **admin** worden als beheerder weergegeven.

Voor een beheerdersaccount zijn bepaalde beheeracties niet beschikbaar. Dit wordt in de interface aangegeven met bijvoorbeeld **Hoofd** of **Beveiligd**.
