Volg de onderstaande stappen om zelf recepten te kiezen:

1. Open het dashboard.
2. Klik op **Handmatig**.
3. Ga naar de receptenpagina.
4. Bekijk de verschillende categorieën.
5. Klik op een recept om de details te bekijken.
