Hieronder vind je een overzicht van veelgebruikte termen binnen de SuriHealth-applicatie.

| Term | Betekenis |
|------|-----------|
| Dashboard | Overzicht van de belangrijkste functies na het inloggen. |
| Navigatiebalk | Menu waarmee gebruikers door de verschillende pagina's van de applicatie kunnen navigeren. |
| Recept | Informatie over een gerecht, inclusief ingrediënten en bereidingswijze. |
| Account | Het persoonlijke gebruikersprofiel. |
| Boodschappenlijst | Lijst met ingrediënten die nodig zijn voor geselecteerde recepten. |
| Favoriet | Een opgeslagen recept voor snelle en eenvoudige toegang. |
