# 🚀 Aan de slag met SuriHealth

Welkom bij **SuriHealth**! Deze gids helpt je om snel te starten.

## 📝 Stap 1: Account aanmaken

1. Ga naar [surichealth.sr](https://surichealth.sr)
2. Klik op de knop **"Registreren"** rechtsboven
3. Vul je **e-mailadres** en een **sterk wachtwoord** in
4. Bevestig je account via de link in de ontvangen e-mail

> 💡 **Tip:** Gebruik je Surinaamse telefoonnummer bij het profiel.

## 📊 Stap 2: Gezondheidsprofiel invullen

Vul je basisgegevens in:

| Veld | Omschrijving |
|------|--------------|
| **Leeftijd** | Je leeftijd in jaren |
| **Gewicht** | In kilogrammen |
| **Bloeddruk** | Bijv. 120/80 mmHg |
| **Bloedgroep** | A+, A-, B+, B-, AB+, AB-, O+, O- |

:::caution[Let op!]
Alleen jij en jouw geautoriseerde zorgverleners kunnen deze gegevens inzien.
:::

## 🏠 Stap 3: Dashboard verkennen

- 📈 Gezondheidsgrafieken
- 📅 Afsprakenoverzicht
- 💊 Medicatieherinneringen
